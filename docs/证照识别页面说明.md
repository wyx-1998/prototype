# 相关方证照识别页面使用说明

## 📄 页面位置
`prototype/certificate_recognition.html`

## ✨ 功能特性

### 1. 表单字段
页面包含完整的营业执照信息录入表单:
- ✅ **资质类型** (必填,默认:营业执照)
- ✅ **统一社会信用代码** (必填)
- ✅ **企业名称** (必填)
- ✅ **成立日期** (必填)
- ✅ **法定代表人** (必填)
- ✅ **注册资本(万元)** (必填)
- ✅ **类型** (必填)
- ✅ **登记机关** (必填)
- ✅ **登记时间** (必填)
- ✅ **住所** (必填,占整行)
- ⭕ **经营范围** (选填,文本域,字数统计0/200)
- ⭕ **资质附件** (选填,支持jpg/png/pdf,最多5个文件)

### 2. AI助手交互

#### 唤醒方式
1. **悬浮按钮** - 点击右下角AI助手图标
2. **AI智能分析按钮** - 上传文件后,在文件列表底部出现"AI智能分析"胶囊按钮
3. **自动弹窗提示** - 上传文件时自动弹出识别提示

#### 对话流程
1. **欢迎语** - "您好,张三!我是您的安全生产AI助手"
2. **上传文件** - 用户上传证照文件(支持图片或PDF)
3. **AI识别** - 显示"正在识别中..."加载动画
4. **结果展示** - 以结构化卡片展示识别的营业执照信息
5. **一键插入** - 点击"插入资质基本信息"按钮,自动填充表单

### 3. 特色功能

#### 🎨 粒子特效
点击"AI智能分析"按钮时,会触发炫酷的粒子飞向右下角的动画效果

#### 🏷️ Skill标签
对话中会显示"证照识别"标签,标识使用的AI能力

#### 📊 字符计数
经营范围字段实时显示字符数量,超过200字时红色警告

#### 💬 消息操作
AI回复的消息支持:
- 🔊 语音播放
- 📋 复制内容
- 👍 点赞
- 👎 踩
- 🔗 转发

## 🚀 快速体验

1. 用浏览器打开 `prototype/certificate_recognition.html`
2. 点击"选择文件"按钮上传任意图片
3. 在弹窗中点击"AI识别"
4. 查看AI助手侧边栏中的识别结果
5. 点击"插入资质基本信息"按钮
6. 查看表单自动填充效果

## 📝 技术实现

- **前端框架**: Vue 3
- **UI组件**: Element Plus
- **图标库**: Phosphor Icons
- **样式**: 复用 `hidden_danger.css`
- **脚本**: `certificate_recognition.js`

## 🔄 与隐患识别页面的区别

| 特性 | 隐患识别 | 证照识别 |
|------|---------|---------|
| 菜单项 | 随手拍ai识别 | 相关方证照识别 |
| 表单标题 | 登记信息 | 项目资质 |
| 上传组件 | 照片墙(picture-card) | 文件列表(file-list) |
| AI Skill | 隐患识别 | 证照识别 |
| 识别结果 | 多个隐患卡片(可多选) | 单个营业执照信息 |
| 插入方式 | 插入到问题描述和整改措施 | 插入到各个表单字段 |

## ⚠️ 注意事项

1. 页面需要在HTTP服务器环境下运行(如Live Server),直接双击打开可能无法加载外部资源
2. 文件上传为前端模拟,实际项目需要对接后端API
3. AI识别为模拟数据,实际项目需要对接OCR服务
4. 建议使用Chrome或Edge浏览器以获得最佳体验
