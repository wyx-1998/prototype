# 随手拍ai识别

## 1. 表单内容

**表单区域 (`.form-card`)** 标题为“**登记信息**”，表单内容使用 CSS Grid 分为三列布局。

字段标题和组件为左右结构，组件采用element ui plus组件

具体字段如下：

| 字段名称                | 类型          | 必填     | 备注                                                         |
| :---------------------- | :------------ | :------- | :----------------------------------------------------------- |
| **地点**                | 文本输入框    | 是 (`*`) | placeholder="请输入内容"，占2/3行                            |
| **所属区域**            | 下拉选择框    | 否       |                                                              |
| **问题所属部门/相关方** | 搜索输入框    | 否       | 输入框底部有提示文案："初步确认问题所属单位"                 |
| **问题描述**            | 多行文本域    | 是 (`*`) | 占满2/3行，字数统计 (0/200)，文本域右侧放置“隐患排查库”蓝色按钮 |
| **建议治理措施**        | 多行文本域    | 否       | 占满整行，字数统计 (0/200)                                   |
| **发现人信息**          | 文本展示      | 否       | 分三列展示：发现人(必填)、发现人部门、发现人班组             |
| **发现日期**            | 日期选择器    | 是 (`*`) | 默认显示当天日期                                             |
| **无需提供整改照片**    | 开关 (Toggle) | 否       | 这是一个开关控件                                             |
| **问题照片**            | 文件上传      | 是 (`*`) | 包含相机图标和“+添加照片”按钮，底部有黄色警告提示：支持jpg/png，最多5张 |
| **问题视频**            | 视频上传      | 否       | 包含相机图标和“+添加视频”按钮，底部有黄色警告提示：支持MP4，最多5个，文件大小不超过50M |

## 2.AI助手交互设计

### 空间限制

- 侧边栏宽度限制为400px
- 在主内容区和表单内容为左右结构

### 触发路径

1. 在问题照片字段内，用户上传了问题照片后，立刻弹窗提示：已检测到用户上传n张照片，是否需要AI助手自动帮您识别照片内的隐患问题？

   操作按钮如下：

   1. 取消：关闭弹窗
   2. AI识别：唤醒右侧AI助手聊天窗，并且在对话框内自动增加用户刚刚上传的照片，对话框内描述为：隐患识别（使用标签的方式显示）识别图中存在的隐患和整改建议。需自动发送对话。

2. 在问题照片字段内，用户上传的问题照片后，在最后一张照片右侧增加显示“AI识别”的按钮，交互为闪亮登场

   点击“AI识别”按钮唤醒右侧AI助手聊天窗，并且在对话框内自动增加问题照片字段内当前上传的所有照片

   对话框内描述为：隐患识别（使用标签的方式显示）识别图中存在的隐患和整改建议。

   由用户自动点击或按下enter键发送后与ai助手对话

3. 在页面的右下角悬浮一个AI助手的圆形图标，用户点击小图标即可唤醒初始化的AI助手聊天窗，用户自定义输入内容与AI助手进行对话

### AI助手对话框

- 初始化的AI助手对话框（垂直居中显示）
  1. 提示：您好，张三！我是您的安全生产AI助手
  2. 对话框：
     1. 提示文案：请输入您的问题...
     2. 操作按钮（左侧）：附件上传、图片上传
     3. 操作按钮（右侧）：语音输入、发送（蓝色主要按钮）
- 发送对话
  1. 发送对话：在对话框上传图片，并输入包含 “隐患”、“隐患识别”或“照片”的文字内容
     1. 未发送时：在对话框上方预览图片，支持点击放大预览图片，鼠标移入图片右上角支持删除图片。
     2. 发送后：图片以合适的大小放一行横向滚动查看，文字内容在图片下方蓝色对话气泡方式展示
  2. AI助手回复：
     - AI模拟分析上传的图片，如果是多张图片则逐一分析，并生成隐患分析卡片
     - 展示**“隐患处理”卡片**，展示ai分析的结果，如果ai分析的隐患有多种，则一种隐患一个卡片
       - 卡片内的元素：
         - 问题名称
         - 问题描述
         - 建议治理措施
         - 操作按钮：导入系统

### AI识别的其他交互说明

1. 隐患识别作为AI助手的Skill存在，在对话框中以标签的方式固定显示，以用于提示后台大模型识别为隐患识别的能力进行使用

### AI助手对话框修改调试内容

1. 顶部标题栏
   - 不要标题区
   - 控制区
     - 在展开/全屏图标左侧增加开启新对话的图标：点击开始新对话
2. 聊天内容区域
   - 机器人和用户发送的消息均不需要头像
   - 聊天内容区域的底色仍然为白色不要灰色
   - 机器人的消息气泡不需要白色底色和边框
   - 用户发送的信息照片单独发送，文字内容用蓝色气泡显示，不需要边框，颜色使用品牌主色调
3. 底部输入区域
   - 底部输入区域工具栏（附件和图片按钮）和操作区（语音和发送按钮）均放在输入框下方，附件和图片按钮居左，语音和发送按钮居右
   - 发送按钮的纸飞机图标颜色为白色
   - 输入框聚焦时不需要变成白色的底色



### AI助手对话样例

- 流程A（用户点击悬浮图标唤醒助手对话）
  1. 机器人欢迎语句：您好，张三！我是您的安全生产AI助手
  2. 用户点击图片上传1张图片，并输入文字内容，点击发送
  3. 机器人自动回复：正在分析中...（需要有合适的加载动画）
  4. 隐藏“正在分析中...”语句，输出分析结果如下，每个分析结果以卡片的形式展示，分析卡片右上角有一个勾选框，支持用户选中卡片。最后一个卡片底部放置按钮：插入问题登记表
     - 电线裸露
       - 问题描述：电线绝缘层破损或缺失，导致内部金属导线直接暴露在外。这种情况极易造成人员触电事故，尤其在潮湿环境或意外接触时风险更高，也可能引发短路和火灾。
       - 整改措施：使用绝缘胶带或绝缘套管对裸露的电线进行包裹，确保电线完全绝缘。
       - 法规依据：《用电安全导则》GB/T 13869-2017 第5.2.1条规定"用电产品应处于完好状态，绝缘应无破损"，第6.2.1条明确要求"电气线路应具有足够的绝缘强度、机械强度和导电能力，其绝缘不应破损"。
     - 管道损坏
       - 问题描述：管道表面出现裂缝、孔洞或严重锈蚀，可能导致液体或气体泄漏。这不仅会造成资源浪费，还可能引发地面湿滑、设备损坏，甚至产生有害气体或液体对环境和人员造成危害。 
       - 整改措施：检查所有管道，对损坏的部分进行更换或修复。
       - 法规依据：《中华人民共和国安全生产法》第三十六条规定"生产经营单位必须对安全设备进行经常性维护、保养，并定期检测，保证正常运转。维护、保养、检测应当作好记录，并由有关人员签字"。
     - 电线固定不当
       - 问题描述：电线未使用专用固定件，处于悬空、拖拽或随意摆放状态。长期摩擦会导致绝缘层磨损，也可能被人员或设备意外拉扯，造成线路断开或短路。
       - 整改措施：使用电线夹或扎带将电线固定在适当的位置，防止电线因移动而磨损。
       - 法规依据：《用电安全导则》GB/T 13869-2017 第6.3.1条规定"电气线路的敷设应稳固，连接应可靠，避免因振动、拉伸、弯曲等导致绝缘破损或接触不良"。
  5. 用户勾选1-3个卡片，点击“插入问题登记表”按钮，将选中的卡片的问题描述通过拼接的方式插入到问题描述的输入框内，整改措施也一样插入到建议治理措施的输入框内。
