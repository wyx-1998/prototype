# 安全生产AI助手八大场景演示问题清单

**适用对象**：售前、销售、方案顾问、演示同事  
**用途**：用于准备客户演示时的提问内容与功能展示重点  
**使用原则**：不要把演示做成“点功能”，而要围绕真实业务问题来提问，让客户看到系统是怎么理解问题、调用能力、输出结果的

---

## 1. 智能问答

### 建议演示问题
- `有限空间作业前，现场安全确认要看哪些关键项？`
- `外委动火作业发现监护不到位，现场第一步应该怎么处理？`
- `高处作业安全带佩戴有哪些强制要求？`
- `某类作业票审批不完整，是否允许开工？`

### 需要体现的功能细节
- 知识库检索：从企业制度、操作规程、法律法规、事故案例中检索相关内容
- 意图识别：识别用户是在问“流程要求”“处置步骤”还是“制度依据”
- 上下文理解：支持连续追问，不是每次都重新开始
- 工具调用：必要时联动制度库、法规库、台账数据、相关表单
- 联网搜索：当本地知识库没有覆盖时，可补充外部公开信息或最新法规动态
- 结构化输出：按“结论 + 步骤 + 依据 + 注意事项”输出
- 结果可追溯：答案中能点开查看制度来源、法规条款、案例出处

### 演示时客户最容易感知的点
- 回答是不是像岗位指引，而不是泛泛聊天
- 能不能给出依据
- 能不能继续追问

---

## 2. 智能问数与报告生成

### 建议演示问题
- `近30天哪个厂区隐患数量最多？哪些隐患整改逾期？`
- `本月高风险作业主要集中在哪些班组？`
- `最近一季度重复发生最多的隐患类型是什么？`
- `本月外委作业相关问题主要集中在哪几个单位？`
- `基于以上分析，生成一份本月安全生产分析简报`
- `把这个结果整理成一份专项汇报材料`

### 需要体现的功能细节
- 自然语言转数据查询：把口语化问题转成可执行查询
- 多源数据关联：自动关联巡检、隐患、培训、台账、作业票等数据
- 指标自动计算：自动汇总数量、趋势、同比环比、占比等
- 风险分析：不只给数，还能给异常点、热点、预警提示
- 下钻追溯：能从汇总结果追到班组、设备、现场、具体记录
- 图表生成：自动形成图表、趋势图、结构图
- 连续追问：上一问之后可继续追问“为什么”“具体是哪些”
- 报告模板选择：月报、周报、专题分析、简报等
- 报告自动生成：基于问数结果直接生成分析简报、专题报告或汇报材料
- 文图一体输出：不仅有图表，还有文字解读、风险总结和改进建议
- 可编辑导出：支持人工修改、导出 Word/PPT/PDF

### 演示时客户最容易感知的点
- 是不是一句话就能问数
- 有没有结论和风险提示
- 能不能追到具体对象
- 能不能从“问到数”直接走到“形成材料”

## 3. 专业知识推送

### 建议演示方式
- 演示“系统主动推送消息/卡片/待办”，而不是用户主动搜索
- 可选择以下几个主动推送场景：
  - `新入场外委人员登录后，系统自动推送本岗位常见风险和注意事项`
  - `电气检修班组开工前，系统自动推送近期高频隐患案例`
  - `夜班值守人员到岗后，系统自动推送异常工况处置要点`
  - `特殊作业审批前，系统自动推送近期法规变化和重点要求`

### 需要体现的功能细节
- 主动触发机制：基于岗位、时间节点、作业类型、风险场景自动触发推送
- 岗位画像：基于岗位、工种、职责匹配知识内容
- 场景化推送：结合当前作业类型、时间节点、季节特点、风险场景推送
- 高频问题驱动：结合历史问答和常见问题做精准推送
- 内容组合：支持法规、制度、案例、图文说明、短视频等形式
- 推送理由展示：说明为什么推这条内容，增强可信度
- 关联学习闭环：支持收藏、再问、进入问答、进入制度原文

### 演示时客户最容易感知的点
- 是不是系统主动推，不用等人来找
- 是不是“千人一面”的群发
- 能不能贴岗位、贴当下场景
- 能不能和问答、文件解读联动

---

## 4. 智能隐患分析

### 建议演示流程
1. 发送一张现场照片
2. AI 自动识别隐患
3. 输出隐患描述、整改建议、参考依据
4. 人工选择后，一键导入系统形成隐患记录
5. 继续追问：`这个问题是否属于重大隐患？判断依据是什么？`

### 建议演示问题
- `识别这张图片里的隐患，并生成规范描述`
- `这个隐患应该怎么整改？对应依据是什么？`
- `将这条隐患导入系统`
- `这个问题是否属于重大隐患？判断依据是什么？`

### 需要体现的功能细节
- 图片识别：识别人员行为、设备状态、环境风险
- 多模态分析：结合图像内容和文字描述综合判断
- 隐患类型匹配：对照隐患排查库进行分类
- 隐患描述生成：自动形成可直接入库的规范描述
- 整改建议：输出具体整改方向
- 参考依据关联：关联标准、规程、制度依据
- 人工确认入库：支持人工选择后导入系统，形成隐患记录
- 重大隐患追问判断：支持继续追问是否属于重大隐患，并给出判断依据
- 历史案例联动：关联类似问题或历史事故案例

### 演示时客户最容易感知的点
- 不是只“看出问题”，还能“生成可入库的隐患描述”
- 有没有整改建议和参考依据
- 能不能导入系统，进入后续处理流程
- 能不能继续判断是否属于重大隐患

## 5. 智能巡检

### 建议演示方式
- 演示“系统在巡检过程中主动识别、主动提示”，而不是用户先提问题
- 可选择以下主动巡检场景：
  - `巡检视频流接入后，系统自动识别未佩戴防护用品、临边防护缺失等问题`
  - `夜班巡检过程中，系统主动标记高风险区域异常情况`
  - `外委作业现场巡检时，系统主动发现违规行为并提示处置建议`
  - `识别现场风险后，系统自动生成巡检记录建议`

### 建议演示问题
- `巡检过程中自动识别现场风险点`
- `识别到问题后自动提示处置建议和法规依据`
- `将识别结果自动生成巡检记录`

### 需要体现的功能细节
- 主动巡检触发：基于视频流、巡检任务、现场画面持续自动识别
- 视频识别：支持视频流或巡检视频自动识别
- 实时风险提示：边巡边提示，不是事后分析
- 隐患点定位：在画面中标出风险位置
- 自动生成描述：自动形成巡检问题描述
- 处置建议输出：给出建议动作
- 记录联动：一键转为巡检记录、隐患记录、整改单
- 法规依据联动：识别后自动匹配相关依据

### 演示时客户最容易感知的点
- 是不是系统主动发现问题，不用等人先提
- 是不是实时辅助
- 能不能边识别边留痕
- 能不能直接进入后续处理流程

## 6. 数据辅助填报

### 建议演示场景
以“相关方入场资质填报”为主场景进行演示。  
例如：外委单位人员入场前，需要提交身份证、特种作业证、培训证明、体检材料等，系统自动识别并辅助完成入场资质填报。

### 建议演示问题
- `上传相关方人员身份证、特种作业证和培训证明，自动完成入场资质填报`
- `自动识别证照有效期，并判断是否满足入场要求`
- `同一人员多份资料信息不一致时，自动提示校验`
- `识别完成后生成待确认清单，并导入相关方入场台账`

### 需要体现的功能细节
- OCR 识别：识别身份证、操作证、培训证明、体检材料等证照文件
- 结构化解析：自动拆解姓名、证号、工种、单位、有效期等字段
- 数据映射：自动回填到相关方入场的系统字段
- 入场规则校验：自动判断证照是否齐全、是否过期、是否符合岗位准入要求
- 冲突校验：同一人员多份资料信息不一致时自动提示
- 人工确认清单：生成待确认项目，方便人工最终把关
- 台账联动：确认后直接导入相关方入场台账
- 填报结果留痕：记录识别来源、人工修改和最终确认过程

### 演示时客户最容易感知的点
- 能不能减少相关方入场资料的重复录入
- 能不能自动判断资质是否齐全、是否有效
- 能不能把人工工作从“逐项录入”变成“重点确认”

## 7. 文件解读

### 建议演示流程
1. 上传或选择一份制度、法规、规程或事故案例文件
2. 系统完成文件识别与解析
3. 自动打开第三方 Tab
4. 在第三方 Tab 中以 HTML 页面展示解读结果

### 建议演示问题
- `帮我解读这份最新安全生产制度，重点变化是什么？`
- `这份法规文件对外委作业管理有哪些直接要求？`
- `这份事故案例里最值得关注的风险教训是什么？`
- `把这份文件提炼成适合班组宣贯的要点`

### 需要体现的功能细节
- 文档解析：支持 PDF、Word、扫描件等
- 要点提炼：自动抽取重点内容
- 条款解读：解释条款是什么意思、适用于什么场景
- 差异比对：新旧版本变化对比
- 角色化输出：按班组、管理层、审批人员等不同对象输出不同重点
- 第三方 Tab 跳转：识别完成后自动打开外部解读页面
- HTML 结果展示：以更易读的 HTML 页面承载摘要、条款、适用场景、注意事项等内容
- 关联问答：从解读结果直接继续追问
- 关联推送：把解读结果推给相关岗位

### 演示时客户最容易感知的点
- 能不能快速看懂文件
- 能不能提炼适用重点
- 能不能自动打开结构化解读页面，而不是只吐一段文本
- 能不能直接为后续宣贯和执行服务

## 8. 智能应急预案生成

### 演示口径说明
客户演示时建议重点体现：  
`在紧急情况下，基于具体场景快速输出应急处置措施和执行指引。`

### 建议演示问题
- `脱硫区域突发有毒气体泄漏，现场应如何处置？`
- `高压设备异常停机并伴随人员轻伤，第一时间要采取哪些措施？`
- `外委作业现场发生火情，现场负责人和监护人员分别应该做什么？`
- `某区域出现有限空间人员不适，当前的应急步骤和注意事项是什么？`

### 需要体现的功能细节
- 场景理解：识别事故类型、作业环境、人员状态、风险等级
- 知识库调用：调取预案库、法规库、制度库、案例库
- 规则推理：根据场景自动判断优先处置步骤
- 应急措施生成：输出处置步骤、岗位分工、注意事项
- 依据关联：给出制度或法规依据
- 协同建议：提示需要联动的部门、物资、上报动作
- 快速分发：可推送至相关岗位或导出处置清单

### 演示时客户最容易感知的点
- 不是提前写文档，而是现场快速出措施
- 给出步骤和分工
- 在关键时刻统一口径

## 四、一句话原则

每个场景都尽量回答客户三个问题：
- `这个问题在我现场是不是真的会发生？`
- `系统除了展示结果，是否真的做了判断、分析、调用和生成？`
- `这个能力能不能直接进入我的业务流程，而不是停留在演示层面？`
