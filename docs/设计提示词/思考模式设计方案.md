# 思考模式（Thinking Mode）设计方案

> 文档版本：v1.0  
> 创建日期：2026-04-09  
> 涉及文件：`prototype/ai-assistant-demo.html`、`prototype/components/ai-assistant.css`、`prototype/components/ai-assistant.js`

---

## 一、背景与目标

现有的隐患识别演示流程为：

```
发送消息 → [正在分析中... 加载动画 2.5s] → 输出分析结果卡片
```

目标是在此基础上增加**思考模式（深度思考）**开关，开启后 AI 在输出结果之前会实时流式展示推理过程，推理完毕后再显示结构化结果卡片，带来更强的透明度与信任感。

---

## 二、竞品设计参考

| 产品 | 设计特征 |
|------|----------|
| Claude | 可折叠的「Thinking」灰色区块，字体偏小，有明显分隔 |
| DeepSeek | 「深度思考」提示词 + 可折叠思维链，收缩后显示「已深度思考(Xs)」|
| Kimi | 「思考」区块用浅灰背景 + 左侧蓝紫色竖线区分，可展开/收起 |
| Gemini | thinking 阶段小字展示，完成后平滑过渡到正式答复 |

**本方案设计原则：**
- 保持现有视觉语言一致（白色背景、`#3366CC` 主色调）
- 思考内容与结果有明显视觉区分但不割裂
- 交互简洁，一个开关控制全部行为

---

## 三、用户体验流程对比

### 普通模式（原有）

```
发送消息
  → [加载动画 2.5s]
  → 输出分析结果卡片（打字机 + 卡片流式展示）
```

### 思考模式（新增）

```
发送消息
  → [思考区块出现，header 显示「正在思考…」]
  → 流式输出思考内容（打字机效果，灰色小字）
  → 思考完成 → 思考区块自动折叠，显示「已完成思考（用时 Xs）[展开 ▿]」
  → 流式输出结果卡片（与普通模式相同）
```

## 四、UI 设计规格

### 4.1 输入区域 — 深度思考开关

**位置：** 输入框下方工具栏，在 📎（附件）和 ⊞（技能）图标右侧

**形态：** Pill 形状图标+文字组合按钮

```
[ 📎 ]  [ ⊞ ]  [ 🧠 深度思考 ]                    [ 🎤 ] [→]
```

| 状态 | 样式 |
|------|------|
| 未激活 | 灰色 `#d0d5dd` 边框，灰色文字/图标 |
| Hover | 蓝色 `#3366CC` 边框，蓝色文字/图标 |
| 激活 | 蓝色实底，白色文字/图标，外发光 + 脉冲呼吸动效 |

**呼吸动效（激活态）：**

```css
@keyframes thinking-pulse {
    0%, 100% { box-shadow: 0 0 0 3px rgba(51, 102, 204, 0.15); }
    50%       { box-shadow: 0 0 0 5px rgba(51, 102, 204, 0.08); }
}
```

---

### 4.2 思考过程区块

**展开态（思考进行中）：**

```
┌─────────────────────────────────────────┐
│ ⟳  正在思考...            （无展开按钮）│  ← 旋转图标 + 灰色文字
│━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│
│ 让我仔细观察这张图片的各个细节...       │  ← 12px 灰色打字机输出
│ 首先，我注意到图片左侧有一些电线...     │
│ 管道表面有明显的锈蚀痕迹...             │
└─────────────────────────────────────────┘
```

**折叠态（思考完成）：**

```
┌─────────────────────────────────────────┐
│ ✓  已完成思考（用时 3.2s）   收起 ▾    │  ← 点击可展开查看详情
└─────────────────────────────────────────┘
```

**视觉规格：**

| 属性 | 值 |
|------|----|
| 背景色 | `#f8f9fb` |
| 左侧竖线 | `3px solid rgba(51,102,204,0.4)` |
| 边框 | `1px solid #e4e8f0` |
| 圆角 | `8px` |
| 思考文字大小 | `12px` |
| 思考文字颜色 | `#888` |
| 行高 | `1.75` |
| 折叠动效 | `max-height` + `opacity` 过渡，`0.35s ease` |

## 五、演示用思考内容文案

流式输出内容（分段模拟推理节奏）：

```
让我仔细观察这张图片中的各个细节...

首先，我注意到图片左侧有几根电线，部分绝缘层看起来有磨损的迹象。电线裸露是高风险隐患，需要重点关注。

接着看管道区域，管道表面有明显的锈蚀和裂缝痕迹，这可能导致液体泄漏，增加地面湿滑风险。

还有一处电线固定方式不规范，没有使用专用线夹，悬空的线路在长期使用中容易因摩擦导致绝缘破损。

综合判断，这张图片共存在 3 处安全隐患，我将结合相关安全法规给出具体的整改建议...
```

## 六、技术实现摘要

### state 新增字段

```js
thinkingMode: false  // 深度思考模式开关状态
```

### 新增方法

| 方法 | 说明 |
|------|------|
| `toggleThinkingMode()` | 切换开关状态，更新按钮 UI |
| `simulateAIAnalysisWithThinking()` | 带思考过程的完整分析流程 |
| `toggleThinkingBlock(blockEl)` | 展开/折叠思考区块 |

### 修改逻辑

`simulateAIAnalysis()` 根据 `state.thinkingMode` 分支：
- `false` → 走原有普通流程
- `true`  → 调用 `simulateAIAnalysisWithThinking()`
