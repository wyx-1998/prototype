## 1. 功能需求

### 1.1 核心功能

#### 1.1.1 智能对话

**功能概述**

提供基于 AI 的智能对话能力，用户可以通过自然语言与 AI 助手交互，获取安全生产相关的咨询和建议。

**功能要点**

**文本消息收发**

- 支持多行文本输入
- 单条消息最多 2000 字符
- 支持 Shift+Enter 换行，Enter 键发送
- 消息按时间顺序展示
- 自动保存对话历史

**流式响应**

- AI 回复内容逐字/逐句显示
- 显示打字动画效果，提升真实感
- 支持中断生成
- 响应超时时间：30 秒

**消息历史**
- 本地存储对话记录
- 支持对话上下文关联
- 自动保存，无需手动操作

**输入限制**
- 空消息不允许发送
- 超过字数限制时提示用户
- 发送中禁用输入框和发送按钮

### 1.2 辅助功能

#### 1.2.1 历史对话管理

**功能概述**

保存用户的历史对话记录，支持查看、搜索、切换和删除历史对话。

**功能要点**

**对话列表**

- 按时间倒序排列
- 分组显示：今天、昨天、7天内、更早
- 显示对话标题（取首条消息前 20 字）
- 显示最后更新时间
- 最多保存 50 条历史对话

**搜索功能**
- 实时搜索（输入时即时显示结果）
- 搜索范围：对话标题
- 无结果时显示提示信息

**对话操作**

- 点击对话项加载历史对话
- 支持删除单条对话
- 删除前需要二次确认

**对话切换**
- 切换对话时保留当前对话状态
- 切换动画流畅自然
- 加载失败时显示错误提示

#### 1.2.2 文件管理

**功能概述**

支持用户上传文件（图片、文档等），并提供文件预览、删除等管理功能。

**功能要点**

**上传方式**
- 点击附件图标选择文件
- 支持同时上传多个文件

**文件限制**

- 支持格式：`.jpg, .jpeg, .png, .gif, .svg, .webp, .doc, .docx, .xls, .xlsx, .pdf, .txt, .csv,.zip,.rar`
- 单个文件大小：≤ 10MB
- 文件数量：≤ 5 个

**文件预览**
- 图片类型：显示缩略图预览
- 文档类型：显示文件图标 + 文件名
- 显示文件大小（自动转换单位：KB/MB）
- 每个文件提供删除按钮

**上传状态**

**上传中状态：**
- 显示旋转的加载图标（Spinner）
- 文件名下方显示"上传中..."文字
- 显示上传进度条（0-100%）
- 整个文件项半透明显示
- 禁用删除按钮，防止误操作
- 禁用发送按钮，直到所有文件上传完成

**上传成功状态：**

- 加载图标消失
- 显示文件预览图或文件图标
- 文字变为"上传成功"，1 秒后自动隐藏
- 恢复正常透明度
- 启用删除按钮

**上传失败状态：**
- 加载图标消失
- 显示红色警告图标
- 文字变为"上传失败"
- 显示失败原因（网络错误、文件过大等）
- 提供"重试"按钮
- 可以删除该文件

**上传进度反馈：**

- 显示百分比进度条（推荐）
  - 进度条从 0% 到 100% 平滑过渡
  - 文字显示"上传中 45%"

**多文件上传：**
- 串行上传：一个接一个上传（避免服务器压力）
- 每个文件独立显示上传状态
- 显示总体上传进度："已上传 2/5"

**错误处理**
- 格式不支持：Toast 提示"不支持的文件类型"
- 文件过大：Toast 提示"文件 xxx.jpg 超过 10MB 限制"
- 数量超限：Toast 提示"最多只能上传 5 个文件"
- 上传失败：显示错误信息 + 重试按钮

#### 1.2.4 语音输入

**功能概述**

支持语音输入功能，用户可以通过语音输入问题，系统自动转换为文字。

**功能要点**

**语音识别**
- 调用浏览器语音识别 API
- 支持中文识别
- 实时显示识别结果
- 识别准确率：≥ 90%

**操作流程**
- 点击麦克风图标开始录音
- 录音中显示音波动画

- 浏览器不支持：隐藏语音按钮
- 麦克风权限被拒绝：提示用户授权
- 识别失败：提示"识别失败，请重试"

## 2. 交互设计详细说明

### 2.1 整体交互架构

#### 2.1.1 组件布局结构

**布局组成**

组件采用固定定位的侧边栏设计，不影响页面主体内容的布局。

```
页面结构
├── 主内容区域（业务页面，自动收缩，不受影响）
├── AI 浮动按钮（右下角固定定位）
└── AI 侧边栏（右侧固定定位，可展开/收起）
    ├── 头部区域
    │   ├── 对话标题
    │   ├── 免责声明链接
    │   └── 控制按钮组（新对话、历史、全屏、关闭）
    ├── 聊天区域（可滚动）
    │   ├── 欢迎消息
    │   ├── 消息列表
    │   └── 分析结果卡片（按需显示）
    ├── 历史对话面板（覆盖层，按需显示）
    │   ├── 返回按钮
    │   ├── 搜索框
    │   └── 对话列表
    └── 输入区域（底部固定）
        ├── 文件预览列表（有文件时显示）
        ├── 文本输入框（多行，自适应高度）
        └── 控制栏
            ├── 工具栏（附件、技能）
            └── 操作按钮（语音、发送）
```

**定位与尺寸**

| 元素 | 定位方式 | 位置 | 尺寸 | 层级 |
|-----|---------|------|------|------|
| 浮动按钮 | fixed | 右下角，距边缘 24px | 56×56px | 999 |
| 侧边栏（桌面） | fixed | 右侧，top: 0 | 420px × 100vh | 1000 |
| 侧边栏（移动） | fixed | 右侧，top: 0 | 100vw × 100vh | 1000 |
| 历史面板 | absolute | 覆盖聊天区域 | 100% × 100% | 10 |

### 2.2 AI 助手唤起与关闭

#### 2.2.1 唤起方式

**方式一：浮动按钮点击**

1. 用户点击右下角浮动按钮
2. 浮动按钮缩放动画（轻微缩小后恢复）
3. 侧边栏从右侧滑入（300ms）
4. 浮动按钮淡出隐藏
5. 输入框自动聚焦

**方式二：页面按钮调用**

- 页面中的指定按钮点击后打开（调用 `AIAssistant.toggleAI()` 方法）
- 支持传参强制打开或关闭

### 4.1 浏览器兼容性

|--------|---------|------|

| 微信浏览器 | 最新版 | 基本支持 |

#### 不支持的浏览器

- IE 11 及以下版本
- 过旧的移动浏览器

---

### 4.2 性能要求

#### 响应时间

| 操作 | 要求 | 说明 |
|-----|------|------|
| 打开/关闭 AI 助手 | ≤ 300ms | 动画流畅 |
| 发送消息 | ≤ 100ms | 即时响应 |
| 文件上传 | ≤ 3s | 10MB 文件 |
| AI 分析 | ≤ 60s | 隐患识别 |
| 证照识别 | ≤ 3s | OCR 识别 |
| 搜索历史 | ≤ 100ms | 实时搜索 |
| 加载历史对话 | ≤ 500ms | 本地存储 |

#### 资源占用

- 组件 JS 文件：≤ 100KB（压缩后）
- 组件 CSS 文件：≤ 50KB（压缩后）
- 内存占用：≤ 50MB
- 本地存储：≤ 5MB

#### 优化要求

- 搜索功能需要防抖处理（300ms）
- 滚动事件需要节流处理（100ms）
- 历史对话列表超过 100 条时需要虚拟滚动
- 图片需要懒加载
- 长列表需要分页或虚拟滚动

---

### 4.3 数据存储

#### 本地存储

使用 localStorage 存储以下数据：

| 数据 | 存储键 | 大小限制 |
|-----|--------|---------|
| 历史对话 | ai_assistant_conversations | 最多 50 条 |
| 当前对话 ID | ai_assistant_current_id | - |
| 用户设置 | ai_assistant_settings | - |

#### 存储策略

- 每次对话更新后自动保存
- 超过 50 条对话时删除最旧的
- 提供清空历史功能
- 存储失败时降级到内存存储

---

### 4.4 安全要求

#### XSS 防护

- 所有用户输入必须进行 HTML 转义
- 不允许执行用户输入的脚本
- 使用 textContent 而非 innerHTML（除非必要）

#### 文件上传安全

- 严格校验文件类型（MIME 类型 + 扩展名）
- 限制文件大小（单个 10MB）
- 限制文件数量（最多 5 个）
- 不允许上传可执行文件

#### API 请求安全

- 使用 HTTPS 协议
- 添加 CSRF Token
- 添加请求签名（可选）
- 设置请求超时时间

#### 数据安全

- 敏感信息不存储在本地
- 对话记录仅存储在用户本地
- 不向第三方传输用户数据

---

### 4.5 可访问性要求

#### 键盘导航

- 所有交互元素支持键盘操作
- Tab 键顺序合理
- Enter 键确认，ESC 键取消
- 提供键盘快捷键（可选）

#### 屏幕阅读器

- 所有图标提供 aria-label
- 重要状态变化提供 aria-live
- 表单元素关联 label

#### 视觉辅助

- 文字与背景对比度 ≥ 4.5:1
- 不仅依赖颜色传达信息
- 提供足够的点击区域（≥ 44×44px）

---

### 4.6 错误处理

#### 网络错误

- 显示友好的错误提示
- 提供重试机制
- 自动重连（可选）

#### API 错误

- 区分不同错误类型
- 显示具体错误原因
- 提供解决建议

#### 本地存储错误

- 存储失败时降级到内存
- 提示用户清理存储空间
- 不影响核心功能使用

---

### 4.7 测试要求

#### 功能测试

- 所有功能点需要测试
- 覆盖正常流程和异常流程
- 测试不同浏览器和设备

#### 性能测试

- 测试响应时间
- 测试资源占用
- 测试并发场景

#### 兼容性测试

- 测试主流浏览器
- 测试不同屏幕尺寸
- 测试移动设备

#### 可访问性测试

- 使用键盘操作测试
- 使用屏幕阅读器测试
- 检查对比度和可读性
