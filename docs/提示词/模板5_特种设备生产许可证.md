# 模板5：特种设备生产许可证

## 适用类型
- 特种设备许可证（生产相关）

## 关键词识别
- 生产许可
- 制造许可

## 字段定义

| 字段名 | 说明 | 格式要求 |
|--------|------|----------|
| 资质类型 | 特种设备生产许可证 | 固定值 |
| 模板类型 | 模板5 | 固定值 |
| 发证机关 | 发证机关名称 | 文本 |
| 发证时间 | 发证时间 | YYYY-MM-DD |
| 证书编号 | 证书编号 | 文本 |
| 有效期至 | 许可证有效期截止日期 | YYYY-MM-DD |
| 许可项目明细表 | 许可项目详细列表 | 数组格式，见下方说明 |
| 源文件 | 完整文件路径 | 文本（必填） |

## 许可项目明细表结构

每个许可项目包含以下字段：

| 字段名 | 说明 |
|--------|------|
| 许可项目 | 项目名称，如：压力容器 |
| 许可子项目 | 子项目名称，如：固定式压力容器 |
| 许可参数 | 参数描述，如：设计压力≤35MPa |
| 备注 | 备注信息 |

## 提取示例

- **资质类型**：特种设备生产许可证
- **模板类型**：模板5
- **发证机关**：国家市场监督管理总局
- **发证时间**：2023-01-10
- **证书编号**：TS1234567890
- **有效期至**：2027-01-09
- **许可项目明细表**：
  - 明细1：
    - **许可项目**：压力容器
    - **许可子项目**：固定式压力容器
    - **许可参数**：设计压力≤35MPa，容积≤500m³
    - **备注**：无
  - 明细2：
    - **许可项目**：压力管道
    - **许可子项目**：工业管道
    - **许可参数**：GC1级、GC2级
    - **备注**：无
- **源文件**：/path/to/特种设备生产许可证.jpg

## 注意事项

1. 许可项目明细表必须以数组格式提取
2. 每个许可项目都要完整提取，包含所有子项目和参数
3. 日期格式统一为YYYY-MM-DD
4. 源文件字段为必填项
5. 如果某个字段无法提取，输出null
6. 如果明细表为空，输出空数组[]
