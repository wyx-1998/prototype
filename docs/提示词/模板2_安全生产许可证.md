# 模板2：安全生产许可证

## 适用类型
- 安全生产许可证

## 字段定义

| 字段名 | 说明 | 格式要求 |
|--------|------|----------|
| 资质类型 | 安全生产许可证 | 固定值 |
| 模板类型 | 模板2 | 固定值 |
| 统一社会信用代码 | 18位代码 | 18位字符串 |
| 企业名称 | 企业全称 | 文本 |
| 法定代表人 | 法人姓名 | 文本 |
| 经济类型 | 经济类型 | 如：国有、民营、外资等 |
| 许可证编号 | 许可证编号 | 文本 |
| 有效期至 | 许可证有效期截止日期 | YYYY-MM-DD |
| 发证机关 | 发证机关名称 | 文本 |
| 发证日期 | 发证日期 | YYYY-MM-DD |
| 单位地址 | 企业详细地址 | 文本 |
| 许可范围 | 许可范围描述 | 文本（最多1000字） |
| 源文件 | 完整文件路径 | 文本（必填） |

## 提取示例

- **资质类型**：安全生产许可证
- **模板类型**：模板2
- **统一社会信用代码**：91110000123456789X
- **企业名称**：北京某某建筑工程有限公司
- **法定代表人**：张三
- **经济类型**：有限责任公司
- **许可证编号**：(京)JZ安许证字[2020]123456
- **有效期至**：2026-05-20
- **发证机关**：北京市住房和城乡建设委员会
- **发证日期**：2023-05-20
- **单位地址**：北京市朝阳区某某街道123号
- **许可范围**：建筑施工（房屋建筑工程、市政公用工程）
- **源文件**：/path/to/安全生产许可证.jpg

## 注意事项

1. 许可证编号格式各地可能不同，原样提取
2. 有效期至和发证日期格式统一为YYYY-MM-DD
3. 许可范围需要完整提取，包含所有许可项目
4. 源文件字段为必填项
5. 如果某个字段无法提取，输出null
