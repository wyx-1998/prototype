# 模板1：营业执照

## 适用类型
- 营业执照

## 字段定义

| 字段名 | 说明 | 格式要求 |
|--------|------|----------|
| 资质类型 | 营业执照 | 固定值 |
| 模板类型 | 模板1 | 固定值 |
| 统一社会信用代码 | 18位代码 | 18位字符串 |
| 企业名称 | 企业全称 | 文本 |
| 成立日期 | 企业成立日期 | YYYY-MM-DD |
| 法定代表人 | 法人姓名 | 文本 |
| 注册资本 | 注册资本金额 | 数值（万元），只输出数字，不含单位 |
| 类型 | 企业类型 | 如：有限责任公司、股份有限公司等 |
| 登记机关 | 登记机关名称 | 文本 |
| 登记时间 | 登记时间 | YYYY-MM-DD |
| 住所 | 企业详细地址 | 文本（必填） |
| 经营范围 | 经营范围描述 | 文本（最多1000字） |
| 源文件 | 完整文件路径 | 文本（必填） |

## 提取示例

- **资质类型**：营业执照
- **模板类型**：模板1
- **统一社会信用代码**：91110000123456789X
- **企业名称**：北京某某建筑工程有限公司
- **成立日期**：2015-03-20
- **法定代表人**：张三
- **注册资本**：5000
- **类型**：有限责任公司
- **登记机关**：北京市市场监督管理局
- **登记时间**：2015-03-20
- **住所**：北京市朝阳区某某街道123号
- **经营范围**：建筑工程施工；工程设计；工程咨询...
- **源文件**：/path/to/营业执照.jpg

## 注意事项

1. 统一社会信用代码必须是18位
2. 注册资本只输出数字，不包含"万元"等单位
3. 日期格式统一为YYYY-MM-DD
4. 住所和源文件字段为必填项
5. 如果某个字段无法提取，输出null
