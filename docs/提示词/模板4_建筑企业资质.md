# 模板4：建筑企业资质证书

## 适用类型
- 建筑业企业资质证书

## 字段定义

| 字段名 | 说明 | 格式要求 |
|--------|------|----------|
| 资质类型 | 建筑业企业资质证书 | 固定值 |
| 模板类型 | 模板4 | 固定值 |
| 统一社会信用代码 | 18位代码 | 18位字符串 |
| 企业名称 | 企业全称 | 文本 |
| 证书编号 | 证书编号 | 文本 |
| 法定代表人 | 法人姓名 | 文本 |
| 注册资本 | 注册资本金额 | 数值（万元），只输出数字，不含单位 |
| 经济性质 | 经济性质 | 如：国有、民营、外资等 |
| 发证机关 | 发证机关名称 | 文本 |
| 发证时间 | 发证时间 | YYYY-MM-DD |
| 有效期 | 证书有效期截止日期 | YYYY-MM-DD |
| 详细地址 | 企业详细地址 | 文本 |
| 资质类型及等级 | 资质类型及等级描述 | 文本（最多1000字），如：建筑工程施工总承包一级 |
| 源文件 | 完整文件路径 | 文本（必填） |

## 提取示例

- **资质类型**：建筑业企业资质证书
- **模板类型**：模板4
- **统一社会信用代码**：91110000123456789X
- **企业名称**：北京某某建筑工程有限公司
- **证书编号**：A1234567890
- **法定代表人**：王五
- **注册资本**：10000
- **经济性质**：有限责任公司
- **发证机关**：北京市住房和城乡建设委员会
- **发证时间**：2022-03-15
- **有效期**：2027-03-14
- **详细地址**：北京市丰台区某某大街789号
- **资质类型及等级**：建筑工程施工总承包一级；市政公用工程施工总承包二级；建筑装修装饰工程专业承包一级
- **源文件**：/path/to/建筑资质证书.jpg

## 注意事项

1. 注册资本只输出数字，不包含"万元"等单位
2. 资质类型及等级需要完整提取，包含所有资质项目和等级
3. 日期格式统一为YYYY-MM-DD
4. 源文件字段为必填项
5. 如果某个字段无法提取，输出null
