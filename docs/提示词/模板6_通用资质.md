# 模板6：通用资质模板

## 适用类型
- 除模板1-5之外的所有资质文件
- 包括但不限于：
  - 质量管理体系认证
  - 职业健康安全管理体系认证
  - 环境管理体系认证
  - 安全生产标准化证书
  - 建造师注册证书
  - 安全员证书
  - 其他职业资格证书
  - 其他行业资质证书

## 说明

本模板适用于所有无法匹配模板1-5的资质文件，采用极简设计，只提取核心信息。

## 字段定义

| 字段名 | 说明 | 格式要求 |
|--------|------|----------|
| 资质类型 | 通用资质 | 固定值 |
| 模板类型 | 模板6 | 固定值 |
| 资质名称 | 从文件内容中识别的资质名称 | 文本，如：ISO9001质量管理体系认证、二级建造师注册证书 |
| 资质附件 | 完整文件路径 | 文本（必填） |

## 提取规则

1. **企业名称识别**（重要）：
   - **个人资格证书**（如建造师、安全员等）：从"聘用企业"、"工作单位"、"所在企业"等字段提取企业名称
   - **企业认证证书**（如ISO认证、体系认证等）：从证书上的"企业名称"、"认证单位"等字段提取
   - **其他证书**：尽可能从证书内容中识别相关企业名称
   - 如果无法识别企业名称，使用"未识别"

2. **资质名称提取**：
   - 从文件内容中识别证书的正式名称
   - 尽可能使用证书上的完整标题
   - 如：ISO9001:2015质量管理体系认证证书、中华人民共和国二级建造师注册证书

3. **资质附件**：
   - 必填字段
   - 使用完整的文件路径

4. **简化原则**：
   - 不提取发证机关、有效期等详细信息
   - 只关注资质名称和文件路径
   - 保持模板简单易用

## 注意事项

1. **极简设计**：本模板只提取最核心的两个字段，不需要复杂的规则
2. **资质名称**：应该能够清楚地说明这是什么资质
3. **资质附件**：必填，用于追溯原始文件
4. **适用范围广**：所有无法匹配模板1-5的文件都使用此模板
