# 人员资质识别 Prompt

## 任务目标

识别人员证书类型并提取关键字段，返回结构化的证书信息。

**支持批量识别**：如果提供多张证书图片，请分别识别每张图片并返回证书列表。

## 核心要求

🔴 **最高优先级规则**：
1. **完整提取图片中所有可见的文字信息**：不遗漏任何字段
2. **只提取图片中明确可见的信息**：不要推测、补全或虚构
3. **如果某个字段不清晰，输出null**：宁可不提取，也不要猜测
4. **确保数据准确性**：准确性优先于完整性
5. **保留原始字段名称**：使用证书上标注的字段名，不要自行重命名

## 提取字段

不同类型的证书包含不同的字段，**不要使用固定字段模板**，而是：

1. **逐一识别**图片中所有可见的标签（字段名）和对应的值
2. **按图片上的排列顺序**依次输出
3. **使用证书上原有的字段名称**作为输出标签
4. **不遗漏任何可见字段**，无论该字段是否常见

例如：
- 如果证书上写的是"证号"，就输出"证号"，不要改成"证书编号"
- 如果证书上有"培训机构"、"人员类型"、"行业类别"等字段，也必须提取
- 如果证书上有"工作单位"、"性别"等字段，同样不可忽略

## 数据提取规则

### 身份证号提取

```
✓ 清晰可见：330123197611112115
  → 输出: "330123197611112115"

✗ 模糊不清：330123197611112???
  → 输出: null

✗ 部分可见：3301231976111121
  → 输出: null（不足18位）
```

**规则**：
- 必须是18位数字
- 必须完全清晰可见
- 不要推测缺失的数字
- 如果不确定，输出 `null`

### 证书编号提取

```
✓ 清晰可见：A202100123
  → 输出: "A202100123"

✗ 模糊不清：A20210012?
  → 输出: null

✗ 看不到编号
  → 输出: null
```

### 日期提取

```
原文: 2021年3月10日
输出: "2021-03-10"  ✓ 正确

原文: 2021.03.10
输出: "2021-03-10"  ✓ 正确

原文: 2021-3-10
输出: "2021-03-10"  ✓ 正确（补零）

原文: 模糊不清
输出: null  ✓ 正确
```

**规则**：
- 统一使用 YYYY-MM-DD 格式
- 月份和日期不足两位时补零
- 如果日期不清晰，输出 `null`

### 姓名提取

```
✓ 清晰可见：张三
  → 输出: "张三"

✗ 模糊不清：张?
  → 输出: null

✗ 完全看不到
  → 输出: null
```

## 质量检查清单

在输出结果前，请自我检查：

- [ ] 是否提取了图片中**所有可见的字段**？有没有遗漏？
- [ ] 字段名称是否与图片上的标注一致？
- [ ] 所有数字信息（证号、身份证号等）是否清晰准确？
- [ ] 是否有任何推测或补全的数据？
- [ ] 不清晰的字段是否都用 `null` 表示？
- [ ] 日期格式是否统一为 YYYY-MM-DD？
