# 模板3：电力设施许可证

## 适用类型
- 特种设备许可证（电力设施相关）

## 关键词识别
- 电力设施
- 承装
- 承修
- 承试

## 字段定义

| 字段名 | 说明 | 格式要求 |
|--------|------|----------|
| 资质类型 | 承装(修、试)电力设施许可证书 | 固定值 |
| 模板类型 | 模板3 | 固定值 |
| 单位名称 | 企业全称 | 文本 |
| 许可证编号 | 许可证编号 | 文本 |
| 法定代表人 | 法人姓名 | 文本 |
| 发证机关 | 发证机关名称 | 文本 |
| 许可证类别和等级 | 类别和等级描述 | 如：承装类一级、承修类二级等 |
| 有效期限 | 许可证有效期截止日期 | YYYY-MM-DD |
| 发证日期 | 发证日期 | YYYY-MM-DD |
| 住所 | 企业详细地址 | 文本 |
| 源文件 | 完整文件路径 | 文本（必填） |

## 提取示例

- **资质类型**：承装(修、试)电力设施许可证书
- **模板类型**：模板3
- **单位名称**：北京某某电力工程有限公司
- **许可证编号**：5-1-00123-2023
- **法定代表人**：李四
- **发证机关**：国家能源局
- **许可证类别和等级**：承装类三级、承修类四级、承试类四级
- **有效期限**：2028-06-30
- **发证日期**：2023-07-01
- **住所**：北京市海淀区某某路456号
- **源文件**：/path/to/电力设施许可证.jpg

## 注意事项

1. 许可证类别和等级需要完整提取，包含承装、承修、承试的所有等级
2. 日期格式统一为YYYY-MM-DD
3. 源文件字段为必填项
4. 如果某个字段无法提取，输出null
