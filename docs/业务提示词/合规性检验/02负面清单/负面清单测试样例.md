# 负面清单测试样例

基于 `docs/合规性检验/负面清单.xlsx` 整理。

说明：
- 覆盖 12 类所属企业类型。
- 每类提供 3 个测试样例：`HIT`、`MISS`、`UNCERTAIN` 各 1 个。
- 样例用于验证“先按企业类型过滤负面清单，再结合项目名称和项目内容进行语义匹配”的判定逻辑。
