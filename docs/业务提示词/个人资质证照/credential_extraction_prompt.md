# 个人资质证照批量识别结构化提示词

你将收到一张证照图片，或一个 PDF 页面渲染出的图片。
你的任务是：
1. 判断这是：`安全合格证`、`特种作业操作证`、`其他`
2. 只提取图片中清晰可见的信息
3. 直接输出 JSON，不要输出解释，不要输出 markdown 代码块

## 识别原则
- 只基于图片中可见内容输出
- 不猜测，不补全，不虚构
- 不清晰的字段填 `null`
- `初领日期` 统一输出为 `YYYY-MM-DD`
- `有效期限` 必须输出完整有效起止日期，格式统一为 `YYYY-MM-DD至YYYY-MM-DD`，例如 `2019-09-20至2024-09-19`
- `应复审日期` 格式统一为 `YYYY-MM-DD前`，例如 `2019-09-19前`
- 如果图片里只能看到部分日期、看不清起止范围、或无法确认“前”字样，则对应字段填 `null`
- 如果不是前两类证照，但仍然是证书、资格证、岗位证、上岗证、培训证、职业资格、特种设备相关证件等个人资质证明，`credential_type` 输出 `其他`
- 如果连个人资质证照都无法确认，`credential_type` 输出 `未识别`

## 输出 JSON 结构
{
  "source_file": "原文件名",
  "file_type": "image|pdf",
  "credential_type": "安全合格证|特种作业操作证|其他|未识别",
  "success": true,
  "fields": {
    "证号": null,
    "姓名": null,
    "性别": null,
    "人员类型": null,
    "行业类别": null,
    "作业类别": null,
    "操作项目": null,
    "证书类别": null,
    "资质名称": null,
    "初领日期": null,
    "有效期限": null,
    "应复审日期": null,
    "签发机关": null
  },
  "issues": []
}

## 字段要求
### 安全合格证
保留这些字段：
- 证号
- 姓名
- 性别
- 人员类型
- 行业类别
- 初领日期
- 有效期限
- 签发机关

### 特种作业操作证
保留这些字段：
- 证号
- 姓名
- 性别
- 作业类别
- 操作项目
- 初领日期
- 有效期限
- 应复审日期
- 签发机关

### 其他
保留这些字段：
- 证号
- 姓名
- 证书类别
- 资质名称
- 有效期限
- 应复审日期
- 签发机关

## 严格要求
- `success` 表示是否成功识别出证照类型并提取出至少一个关键字段
- `issues` 里简短写出识别问题，例如：`["姓名不清晰", "证号缺失"]`
- 没有看到的字段填 `null`
- 不要把 `有效期限` 只输出成单个日期
- 不要省略 `应复审日期` 的 `前`
- 最终只能返回一个合法 JSON 对象
